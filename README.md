# Bleep Homebrew tap

Install and update Bleep's CLI and MCP on Apple Silicon, macOS 13 or later.

The first public signed release is in preparation. No installable formula is published yet.

When the release is ready, install with `brew install MauScheff/bleep/bleep`. Update with `brew update` followed by `brew upgrade MauScheff/bleep/bleep`. Pairing, credentials and host configuration remain outside Homebrew's package directories.

Binary downloads and third-party sources will be hosted in [MauScheff/bleep-releases](https://github.com/MauScheff/bleep-releases).
